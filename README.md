# Extra-Credit-Task

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/sri-vishnu-001/Extra-Credit-Task/blob/main/Supervised_ML_Engineering_Tutorial.ipynb)

A tutorial on data preprocessing, regression and classification with scikit-learn, using a car fuel-economy dataset.

## Run it online (no installation)

1. Click **Open in Colab** above.
2. Choose *Runtime → Run all*. The first code cell downloads the datasets automatically.
3. Before you make changes, choose *File → Save a copy in Drive*. Colab does not keep edits to the shared copy.

## Extra-credit task

Section 8 of the notebook lists six datasets (three regression, three classification). Pick one and apply the same steps as Sections 1–7.

## Run it locally (optional)

Requires Python 3.10+ with `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn` (1.4 or newer) and `joblib`. Download or clone this repository and open the notebook from the repository folder, so the `Datasets/` folder is next to it.

## Contents

| Path | Description |
|---|---|
| `Supervised_ML_Engineering_Tutorial.ipynb` | The tutorial notebook |
| `Datasets/Regression/` | `automobiles.csv` (tutorial), `FuelConsumptionCo2.csv`, `kc_house_data.csv`, `manhattan_Housing.csv` |
| `Datasets/Classification/` | `diabetes.csv`, `titanic.csv`, `Orange_Telecom_Churn_Data.csv` |

Datasets originate from the public [AP-State-Skill-Development-Corporation/Datasets](https://github.com/AP-State-Skill-Development-Corporation/Datasets) repository.
